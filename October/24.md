Paizaでは、標準入力の課題が続いていた。
標準入力値が二つある場合
```
s, t = gets.split(' ')

puts s
puts t
```
これは、多重代入というらしい。
入力値が、hello と paoza の二つだった場合、それぞれ s に hello が代入され、 t には  paiza が代入される。
```
ary = gets.split(' ')
s = ary[0]
t = ary[1]
```
このような動きになっている。
