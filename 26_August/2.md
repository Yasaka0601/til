AI によるリファクタ

```ruby
len, _, people = gets.split.map(&:to_i)

card = Array.new(len) { gets.split.map(&:to_i) }

count = gets.to_i
logs = Array.new(count) { gets.split.map(&:to_i) }

answerer = 1

logs.each do |log|
  r1, c1, r2, c2 = log.map { |n| n - 1 }

  if card[r1][c1] == card[r2][c2]
    puts "YES"
  else
    puts "NO"
    answerer = answerer % people + 1
  end
end

puts answerer
```

リファクタのポイント

```ruby
# 変更前
card = []
len.times do
  card << gets.split.map(&:to_i)
end

# 変更後
card = Array.new(len) { gets.split.map(&:to_i) }
```

`Array.new` を使うと、一行にまとまる。

```ruby
# 変更前
count.times do |i|
  l_index_1 = memo[i][0] - 1
  w_index_1 = memo[i][1] - 1
  l_index_2 = memo[i][2] - 1
  w_index_2 = memo[i][3] - 1

# 変更後
logs.each do |log|
  r1, c1, r2, c2 = log.map { |n| n - 1 }
```

each にして、mapを使うことで `memo[i][0]` のようにする必要がなくなる。
map で全要素に -1 をして 多重代入をする。
