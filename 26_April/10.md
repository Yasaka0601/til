# Ruby チェリー本

## ハッシュのキーにシンボルを使う

```ruby
{ シンボル: 値 }
```

という記述になる。

---

## 値を取り出す時は、コロンの位置が左から右に変わる。

```ruby
currencies = { japan: 'yen', us: 'doller', india: 'rupee' }
currencies[:japan] #コロンの位置が左になる。
```

---

## キーと値の両方がシンボル

両方がシンボルの場合、コロンが向き合う記述となる。

```ruby
currencies = { japan: :yen, us: :doller, india: :rupee }
```

## 慣れないうちは、コロンの位置で混乱する。

コロンの位置は

### 右側　シンボルである

### 左側　シンボルがキーのハッシュから値を取り出す。

### 全パターン

```ruby
# ① シンボルそのもの（値として使う）
:name          # コロンが左側

# ② ハッシュの定義（キーがシンボルの省略記法）
{ name: "アリス" }   # コロンが右側
# { :name => "アリス" } と同じ意味

# ③ ハッシュから取り出す
hash[:name]    # コロンが左側（シンボルで指定）

# ④ メソッドの引数にシンボルを渡す（位置引数）
convert_length(1, :m, :in)   # コロンが左側（シンボルという値を渡すだけ）

# ⑤ キーワード引数で渡す
greet(name: "アリス")   # コロンが右側

# ⑥ キーワード引数で受け取る（定義側）
def greet(name:)      # コロンが右側（コロンで終わる）
```

メソッドの引数で

```ruby
convert_length(1, :m, :in)
```

というのは、値を取り出しているのではなく、引数がシンボル。

なので、ハッシュのキーのデータ型を合わせる（キーをシンボルにする）
