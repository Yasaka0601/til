# 正規表現

（そろそろ先に進みたい）

Ruby では文字列が正規表現にマッチすると MatchDataオブジェクトが返る

```ruby
#<MatchData "1993年6月1日" 1:"1993" 2:"6" 3:"1">
```

`オブジェクト[1]` のようにしてマッチした値を取り出すが  `?<year>` と記述すると 

`オブジェクト[:year]` で取り出すことができる。

これを「名前付きキャプチャ」という
