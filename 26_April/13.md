# Ruby チェリー本

## 正規表現について

- \d など、特別な文字を「メタ文字」という。
- \d は「一個の半角数字」を検索する。
- Ruby では

```ruby
//
```

で囲まれだ部分が正規表現となる。

- 文字の個数を限定する時は

```ruby
{n,m}
```

を使う。

直前の文字がn個以上、m個以下という意味。

```ruby
{n}
```

は直前の文字がちょうどn文字という意味。

- 「[ ]」の使い方。

```ruby
[a-z]
```

は「aまたはbまたはcまたは・・・yまたはz」　という意味。

```ruby
[-az]
```

は「a または z または - 」のいずれか一文字という意味。

- ? の使い方

? は「または無し」を表現するために使用。【量指定子】

- . は任意の一文字という意味。

つまり

```ruby
.?
```

とすると、「任意の一文字若しくは無し」という意味になる。
