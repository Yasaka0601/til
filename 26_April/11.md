## nil ガード

```ruby
||=
```

を使う。

```ruby
limit ||= 10
```

変数 limit が nil または false なら、10 を limit に代入。

## !! を使った真偽値の型変換

```ruby
def user_exists?
  user = find_user
  if user
    true
  else
    false
  end
end
```

上記のように true と false を返すメソッドがある。

```ruby
!!
```

を使えば

```ruby
def user_exists
  !!find_user
end
```

というようにコンパクトに記述できる。

!! は

```ruby
irb(main):001:0> !!true
=> true
irb(main):002:0> !!1
=> true
irb(main):003:0> !!false
=> false
irb(main):004:0> !!nil
=> false
```

のように true か false を返す。
