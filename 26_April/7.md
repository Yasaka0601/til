## ブロック

do end と { } はブロック

よく使う | n | の | | はブロックパラメータ

ブロックを省略するには **&:** を使う。

&: を使う条件は３つある。

1. ブロックパラメーターが１つだけ。
2. ブロックの中で呼び出すメソッドが１つだけ。
例：　{ | n | n.upcase } 
3. ブロックの中で、ブロックパラメータに対してメソッドを１回しか呼び出さない。

```ruby
['ruby', 'java' , 'python' ].map { |n| n.upcase } 
```

これを

```ruby
['ruby', 'java' , 'python' ].map(&:upcase)
```

のように省略できる。

## スプラット演算子

配列を引数に渡す場合、「一つの配列」を「複数の引数」として渡す方法。

通常

```ruby
a = [1]
b = [2, 3]

a.push(b)
a #=> [1,[ 2, 3]]
```

のように、二次元配列となってしまう。

‘ * ‘ を使った場合

```ruby
a = [1]
b = [2, 3]

a.push(*b)
a #=> [1, 2, 3]
```

というように引数に * を付けると、配列を複数の引数として渡すことができる。
