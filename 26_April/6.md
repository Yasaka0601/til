# 本日の学習内容

## LT会資料作成
学習というより、LT会のプレゼン資料の作成に没頭した。
推しのメソッド・ライブラリを紹介するというものである。

メソッドを紹介するにあたり、やはり実行してみるというのが一番のプロセスだと思ったので、簡単なコードを作成した。

ここでは簡単に調べたことを記述する

- inject
畳み込み演算をする。
具体的には、配列の要素を一つずつ取り出して、前の計算結果と合わせて処理をする。
each を使って同じことを実現することができるが、each は修正する変数を用意する必要がある。

余談であるが、inject は Google が開発した TPU と似ているような気がする。
行列計算をするという点で似ているような気がする。
inject の内部構造を確認すると違うのかもしれないが。

- inspect
このメソッドだけ配列操作のメソッドではない。
デバックで使用するメソッドである。
エンジニア転職チャンネルでは、inspect を使ってログにプリントデバックをしていた。
p と puts の違いについてまとめた。

- detect
このメソッドを使う機会がなさそうだ。
というのも、このメソッドは、find と全く同じで「条件にある最初の要素を取得」するメソッドだ。
ぶっちゃけ、そんなシュチュエーションがあるのだろうか。

- select
これはよく使用するメソッドで、条件に合うメソッドを全て取得する。
特に説明の必要がない。

- reject
select の逆。
条件に合わないメソッドを全て取得。
何かに使えそう。

- collect
map と同じ。
配列全ての要素に処理を行う。
