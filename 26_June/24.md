## テーブル設計

!成績 (1).png.png)

正解数だけでなく選択肢についても記録として残したいので、回答の選択肢を記録するquiz_history_choices を作成。

course_results テーブル。

役割：ユーザーとコースを紐づける。
　　　クイズ数と正解数を記録する。

- correct_count カラム：正解数のカウント
- total_questions カラム：コースの問題数

quiz_histories テーブル。

役割：course_results とクイズ本文（quiz_id）を紐づける。

quiz_history_choices テーブル（中間テーブル）

役割：回答選択肢（choice_id）とquiz_histories を紐づける。

## アソシエーション

CourseResult

```ruby
  belongs_to :user
  belongs_to :course

  has_many :quiz_histories, dependent: :destroy
```

ユーザーに属する。（ user  1 対 多 CourseResult ）

コースに属する。（ course  1 対 多 CourseResult ）

複数のquiz_histories を持つ。（ CourseResult 1 対 多 quiz_histories ）

QuizHistory

```ruby
  belongs_to :course_result
  belongs_to :quiz

  has_many :quiz_history_choices, dependent: :destroy
  has_many :choices, through: :quiz_history_choices
```

course_result に属する。（ course_result 1 対 多 QuizHistory ）

クイズに属する。（ quiz 1 対 多 QuizHistory ）

複数の quiz_history_choices を持つ（ QuizHistory 1 対 多 quiz_history_choices ）

複数の choices 中間テーブル quiz_history_choices を経由して持つ
（ QuizHistory 多 対 多 choices ）

QuizHistoryChoice

```ruby
  belongs_to :quiz_history
  belongs_to :choice
```

quiz_history に属する。（ quiz_history 1 対 多 QuizHistoryChoice）

choice に属する。（ choice 1 対 多 QuizHistoryChoice )

つまり、quiz_history と choice の中間テーブルとなる。

# class CourseResult

```ruby
  def self.build_from_session!(user:, course:, quiz_ids:, answers:)
   
    course_result = CourseResult.create!(
      user: user,
      course: course,
      correct_count: 0,
      total_questions: quiz_ids.size
    )

    tally = course_result.build_quiz_histories!(quiz_ids: quiz_ids, answers: answers)

    course_result.update!(correct_count: tally[:correct_count]) if tally[:correct_count].positive?

    user.increment!(:total_point, tally[:earned_point]) if tally[:earned_point].positive?

    user.course_results.order(created_at: :desc).offset(20).delete_all

    course_result.newly_granted_badges = course_result.course_challenge_record || []

    course_result
  end
```

クラスメソッドで定義

```ruby
self.build_from_session!(user:, course:, quiz_ids:, answers:)
```

なぜ、クラスメソッドにするのか。

build_from_session! を呼んだ時点では、まだレコードが存在していないから。

このクラスメソッド内で `CourseResult.create!` をすることが目的なので、クラスメソッドにする必要がある。

`!` を付ける意図は、失敗すればエラーを発生させるため。

`!` がなければ、nil を返すことになる。

引数は、シンボルを使いキーワード引数にしている。

---

```ruby
course_result = CourseResult.create!(
      user: user,
      course: course,
      correct_count: 0,
      total_questions: quiz_ids.size
    )
```

CourseResult（このクラス自身） のインスタンスを生成して、変数course_result に代入。

`self`を使っても良いが、クラスメソッド内では `self` が何を指すのか分かりにくいので、非推奨。

以降、この course_result を使って、quiz_histories や quiz_histories_choice を作成していく。
そうすることで、自動的に紐付けされる。

---

```ruby
tally = course_result.build_quiz_histories!(quiz_ids: quiz_ids, answers: answers)
```

tally （訳：集計）　に quiz_histories のインスタンスを代入。

`course_result.build_quiz_histories!` のように、course_result にメソッドをチェーンすることで、course_result の id に紐付く quiz_histories を作成できる。

引数はコントローラーから受け取った quiz_ids と answers

## build_quiz_histories!

```ruby
  def build_quiz_histories!(quiz_ids:, answers:)
    correct_count = 0
    earned_point = 0

    quizzes = Quiz.where(id: quiz_ids).index_by(&:id)

    quiz_ids.each_with_index do |quiz_id, index|
      quiz = quizzes[quiz_id]
      evaluation = QuizAnswerEvaluator.call(quiz: quiz, answer: answers[index])
      quiz_history = quiz_histories.create!(quiz: quiz)
      evaluation.selected_ids.each do |choice_id|
        quiz_history.quiz_history_choices.create!(choice_id: choice_id)
      end

      if evaluation.correct?
        correct_count += 1
        earned_point += quiz.give_point.to_i
      end
    end

    { correct_count: correct_count, earned_point: earned_point }
  end
```

```ruby
quizzes = Quiz.where(id: quiz_ids).index_by(&:id)
```

DB から Quiz レコードを取得。

quizzes にはハッシュ形式のクイズオブジェクトが格納されている。

`Quiz.where(id: quiz_ids)` は配列のようなもの（クイズオブジェクトの集まり）を返す。

`.index_by(&:id)` はそれを**ハッシュに変換する。**

```ruby
# 変換前（配列のようなもの）
[#<Quiz id:1, ...>, #<Quiz id:2, ...>, #<Quiz id:3, ...>]

# .index_by(&:id) 変換後（ハッシュ）
{
  1 => #<Quiz id:1, ...>,
  2 => #<Quiz id:2, ...>,
  3 => #<Quiz id:3, ...>
}
```

これは N + 1 対策で、ハッシュにしてキャッシュしておくことで、後のループ内で毎回DBにアクセスするのを防いでいる。

ハッシュを作成することで DB へのアクセスを一回にしている。

`&:id` は `{ |quiz| quiz.id }` の省略記法。

---

```ruby
quiz_ids.each_with_index do |quiz_id, index|
```

`quiz_ids = [1, 4, 5, 2, 3]` のような配列に `.each_with_index` をする。

1周目は `quiz_id = 1, index = 0`

2周目は `quiz_id = 4, index = 1` となる。

index はループカウンター。

---

```ruby
quiz = quizzes[quiz_id]
evaluation = QuizAnswerEvaluator.call(quiz: quiz, answer: answers[index])
```

`quizzes[quiz_id]` 先ほど作成したハッシュに [quiz_id ] でオブジェクトを取得し、変数quizに代入している。

`QuizAnswerEvaluator.call(quiz: quiz, answer: answers[index])` 
これについては、別途ドキュメントを作成。https://app.notion.com/p/377260cab82f80ba9b29ce168dbf77d9?source=copy_link#377260cab82f8045ba41c41a6eea46b8

簡単に言うと、正解、不正解などを返すインスタンスを生成できる。

`answers[index]` でユーザーが選択した回答を取得。

`answers` はコントローラーから受け取った回答の配列。

`index` を使うことで、このクイズ（`quiz_id`）に対応する回答（`answers[index]`）」を正しく紐付けている。

```ruby
quiz_history = quiz_histories.create!(quiz: quiz)
```

アソシエーションを経由することで、 quiz_histories に course_result の id が自動でセットされる。

経由しない記述は以下のようになる。

```ruby
# クラスから直接
QuizHistory.create!(course_result: course_result, user: user, quiz: quiz)
# → course_result_id を自分で渡す必要がある
```

なので、アソシエーションを経由した方がコードが簡潔になる。

---

```ruby
evaluation.selected_ids.each do |choice_id|
  quiz_history.quiz_history_choices.create!(choice_id: choice_id)
end
```

`evaluation.selected_ids` はユーザーが選んだ選択肢を返す。
例：単一選択肢の問題 `[1]` 、複数選択肢の問題 `[1, 2]`
それを each で繰り返す。

`selected_ids` は `QuizAnswerEvaluator` で定義されているメソッド

`quiz_history.quiz_history_choices` については、上記と同様にアソシエーション経由でquiz_history_choices を作成している。

```ruby
course_result.update!(correct_count: tally[:correct_count]) if tally[:correct_count].positive?
```

この記述は 後置 if （例：「これをしろ　if　この条件に一致するとき」）

集計結果のインスタンスである `tally` を使用して、course_result に値を入れていく。

`tally[:correct_count].positive?`  の `positive?` は 0 より大きい場合に true を返す。
そうでない場合に false を返す。

https://docs.ruby-lang.org/ja/latest/method/Numeric/i/positive=3f.html

```ruby

```

`increment!` は Rails（ActiveRecord）のメソッド

指定したカラムの値に数値を加算して、即座に DB に保存する。

```ruby

# user.total_point += tally[:earned_point] して save! するのと同じ
```

---

```ruby
user.course_results.order(created_at: :desc).offset(20).delete_all
```

１ユーザーにつき、成績の記録は２０件まで。

`.offset(20)` は「先頭の20件をスキップする」というメソッド。

`新しい順に並べた course_results：
1件目（最新）
2件目
...
20件目
─────── ← offset(20) でここまでスキップ
21件目  ← ここから delete_all
22件目
...`

新しい順に20件並べて、それより古いものを全て削除。常に最新２０件だけ残している。
