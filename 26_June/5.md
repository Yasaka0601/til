## CSS にクラスを追加する。

まず、window オブジェクトに対し、addEventListener で イベントを load に設定する。
これにより、ロードが終わったら処理を実行するというトリガーを指定。

本題のクラスを追加するメソッドは `.classList.add('クラス名')` である。

文法は

```jsx
htmlの要素.classList.add('追加したいクラス');
```

と記述する。

逆に、クラスを削除したい時は

```jsx
htmlの要素.classList.remove('削除したいクラス');
```

と記述する。

トグルボタンの場合は

```jsx
htmlの要素.classList.toggle('ON,OFFにしたいクラス');
```

と記述する。

## **DOM (Document Object Model)**

オブジェクト指向の考え方と似ている。

html のタグは、それぞれ持っているプロパティが違う。

共通のプロパティもあるが、タグ独自のプロパティも存在する。

この仕組みを  **DOM (Document Object Model) と呼ぶ。**

## if 文の省略方法

true の時、false を代入。
もしくは false の時 true を代入するという条件があったとする。
if 文で表現。

```jsx
isAgreed.addEventListener('change', () => {
    if (isAgreed.checked === true ){
        btn.disabled = false;
    } else {
        btn.disabled = true;
    }
});
```

このコードは `!` を使えば以下のように、かなり省略できる。

```jsx
isAgreed.addEventListener('change', () => {
    btn.disabled = !isAgreed.checked;
});
```
