# paiza

問題：1行目に行数を表す整数 n、続く n 行の各行で「文字」と「整数」の組が空白区切りで入力されます。
n 個の組について、「文字」の値が同じ組同士の数値を足しあわせてまとめ、まとめた数値の降順で、文字とまとめた数値の組を出力してください。
この際、まとめた数値は重複しません。

自分の回答（テスト不合格）

```ruby
list = {}
array = []
gets.to_i.times do
  text, integer =  gets.chomp.split(" ")
  list[text] = integer
  array << list
end

p array
```

課題：キーが重複した際、値を合算することが出来ない。

AI によるヒント（以前にもやったと指摘される）

```ruby
list = Hash.new(0)  # 初期値を0にする

list[text] += integer.to_i  # キーが重複したら合算される
```

課題：list の値で降順に並び替える方法がわからない。

AI によるヒント（これも以前にやったと指摘）

```ruby
# キーで降順
hash.sort_by { |key, value| -key }

# 値で降順
hash.sort_by { |key, value| -value }
```

自分の回答

#array = []

**解説**

**Hash(0)**

```ruby
list = {}
list["a"] += 1  # => エラー！ nil + 1 はできない

list = Hash.new(0)
list["a"] += 1  # => 1（0 + 1）
list["a"] += 2  # => 3（1 + 2）
```

**存在しないキーにアクセスした時に `nil` の代わりに `0` を返す**ことで、`+=` が使えるようになります

### sort_by の解説

ruby

```ruby
list = {"b" => 5, "a" => 10, "c" => 3}

# 値で昇順
list.sort_by { |key, value| value }
# => [["c", 3], ["b", 5], ["a", 10]]

# 値で降順（マイナスをつける）
list.sort_by { |key, value| -value }
# => [["a", 10], ["b", 5], ["c", 3]]
```

**マイナスをつけると降順**になります。
