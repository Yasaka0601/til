```sql
select title avg(rating) as avg_rating
from books
join reviews
on books.id = reviews.book_id

having raviews.book_id.count >= 2;
```

模範回答

```sql
SELECT books.title, AVG(reviews.rating) AS avg_rating
FROM books
JOIN reviews ON books.id = reviews.book_id
GROUP BY books.id, books.title
HAVING COUNT(reviews.id) >= 2
ORDER BY avg_rating DESC;
```

## GROUP BY が理解できない。

具体的には、何のカラムを GROUP BY すれば良いのか分からない。

例題：

- books.title（書籍タイトル）
- 平均評価を avg_rating という名前で取得

```sql
SELECT books.title, AVG(reviews.rating) AS avg_rating
FROM books
JOIN reviews ON books.id = reviews.book_id
```

JOIN した後、このようなテーブルができたとする。

```sql
| books.id | books.title      | reviews.rating |
|----------|------------------|----------------|
| 1        | ハリー・ポッター    | 5              |
| 1        | ハリー・ポッター    | 4              |
| 1        | ハリー・ポッター    | 3              |
| 2        | 君の名は           | 5              |
| 2        | 君の名は           | 4              |
```

GROUP BY books.id だけの場合は、books.id だけで

```sql
【id=1のグループ】
| books.id | books.title      | reviews.rating |
|----------|------------------|----------------|
| 1        | ハリー・ポッター    | 5              |
| 1        | ハリー・ポッター    | 4              |
| 1        | ハリー・ポッター    | 3              |
          ↓ 集約すると
| books.id | AVG(rating) |
|----------|-------------|
| 1        | 4.0         |

【id=2のグループ】
| books.id | books.title | reviews.rating |
|----------|-------------|----------------|
| 2        | 君の名は     | 5              |
| 2        | 君の名は     | 4              |
          ↓ 集約すると
| books.id | AVG(rating) |
|----------|-------------|
| 2        | 4.5         |

```

のように、title を表示したいのに、集約した表に title がない。

なので、GROUP BY に books.title を含める。

すると以下のように集約できる。

```sql
【id=1, title=ハリー・ポッターのグループ】
| books.id | books.title      | reviews.rating |
|----------|------------------|----------------|
| 1        | ハリー・ポッター    | 5              |
| 1        | ハリー・ポッター    | 4              |
| 1        | ハリー・ポッター    | 3              |
          ↓ 集約
| books.id | books.title      | AVG(rating) |
|----------|------------------|-------------|
| 1        | ハリー・ポッター    | 4.0         |

```

**「新しいテーブルを作る」というより「データをグループに分けて、各グループを1行にまとめる」**

AVG や COUNT などの集約関数は GROUP BY に含めなくても良い。

# Ruby 初めて知ったメソッド

## max_by

https://docs.ruby-lang.org/ja/latest/method/Enumerable/i/max_by.html

```sql
a = %w[albatross dog horse]
a.max_by(2)                 # => #<Enumerator: ["albatross", "dog", "horse"]:max_by(2)>
a.max_by(2) {|x| x.length } # => ["albatross", "horse"]

```

## min_by

https://docs.ruby-lang.org/ja/latest/class/Enumerable.html#I_MIN_BY

```sql
a = %w(albatross dog horse)
a.min_by                    # => #<Enumerator: ["albatross", "dog", "horse"]:min_by>
a.min_by { |x| x.length }   # => "dog"
a.min_by(2)                 # => #<Enumerator: ["albatross", "dog", "horse"]:min_by(2)>
a.min_by(2) {|x| x.length } # => ["dog", "horse"]

```

## values

ハッシュの全値を返す。

```sql
h1 = { "a" => 100, 2 => ["some"], :c => "c" }
p h1.values         #=> [100, ["some"], "c"]
```
