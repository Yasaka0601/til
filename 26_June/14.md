### オブジェクト（Ruby でいうところのハッシュ）での情報取得方法。

ドット記法

`オブジェクト名 . キー` 

このように . を使って取得する。

ブラケット記法

`オブジェクト名['キー']` 

このように、[ ] で文字列を渡して取得する。

基本的にドット記法で良いが、変数や定数を使って値を取得する場合、ブラケット記法となる。

例

```jsx
  const strawberry = {
    name : 'いちご',
    img : 'strawberry.jpg',
    price :  450,
};

const const_key = 'name';
let let_key = 'img'

console.log(strawberry[const_key]); //=> いちご
console.log(strawberry[let_key]); //=> strawberry.jpg
```

### 分割代入

本には「今回のように、オブジェクトのキーと同じ定数名を使う場合は、さらに省略して記述できます。分割代入と言って、一度に複数のプロパティの値を定数に代入できるようになります。」
と記述されているが、わからない。

「キーと同じ定数名を使う場合」

```jsx
const name  = lists[i].name;   // 定数名「name」 = キー「name」 ← 同じ！
const img   = lists[i].img;    // 定数名「img」  = キー「img」  ← 同じ！
const price = lists[i].price;  // 定数名「price」= キー「price」← 同じ！
```

このように、定数名とキーが同じ。

定数名とキーの名前が同じなら、省略できる。

```jsx
const { name, img, price } = lists[i]
```

「なぜこう動くのか」より「同じ名前が2回出てきたら1行にまとめられる」と覚えれば十分
