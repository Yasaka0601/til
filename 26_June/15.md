# SQl ノック

SQL はとにかく書いて身につける。

自分の回答

```sql
select *
from categories
where name = 'Action' or name = 'Comedy';
```

模範回答

```sql
SELECT *
FROM categories
WHERE name IN ('Action', 'Comedy');
```

学んだこと

WHERE 句で or 条件を使う場合、IN 演算子を使った方が簡潔に記述することができる。
