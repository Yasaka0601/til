# JavaScript

### Web Animations API の基本の記述

```jsx
動かす要素.animate(第一引数の動かす要素, 第二引数の再生時間);
```

### 第一引数の動かす要素の記述方法。

動かす内容は、キーフレームと呼ぶ。

キーフレームはオブジェクト（キー : 値 ）にして、値は配列を用意する。

```jsx
動かす要素.animate({
  キー（プロパティ名) : ['開始の値', '終了の値'],
}, 再生時間);
```

第一引数は、定数にまとめた方がスッキリする

```jsx
const keyframes = { 
  キー(プロパティ名) : ['開始の値', '終了の値'],
};

動かす要素.animate(keyframes, 再生時間);
```

### 動きの詳細の記述

記述例

```jsx
動かす要素.animate({
  // 動かす内容（キーフレーム）の指定
  キー(プロパティ名) : ['開始の値', '終了の値'],
}, {
  // 動きの詳細（タイミング）の指定
  キー(プロパティ名) : '値',
});
```

こちらも分かりずらいので、定数にまとめる。

```jsx
const keyframes = {
  キー(プロパティ名) : ['開始の値', '終了の値'],
};

const options = {
  キー(プロパティ名) : '値',
};

動かす要素.animate(keyframes, options);
```

この場合、必ず duration オプションを記述しなければならない。

なぜなら、再生時間の指定を必ずする必要があるため。

### querySelectorAll

querySelector() で指定した要素が複数存在する時、初めの要素しか取得できない。

全ての要素を取得するためには、querySelectorAll() を使用する。
