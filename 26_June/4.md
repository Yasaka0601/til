# CI とは？

Continuous Integration（継続的インテグレーション）
基本情報技術者で習ったけど、結局何？

簡単に言うと `git push` で自動でテストを実行してくれる。
自動テストのトリガーは任意で設定できる。
私の個人開発アプリの場合、プルリクエスト作成がトリガーとなっている。

---

# CD とは？

Continuous Delivery （継続的デリバリー）

自動でデプロイしてくれる仕組み。
CI と同じく、トリガーは任意で設定可能。
私のアプリの場合、マージがトリガーとなっている。

---

# 本題「Jenkins」とは？

ビルドとテストを自動化する。
（ビルドとは、実行できる状態に準備する。コンパイルはビルドの一部）

ビルドやテストに失敗した時、Jenkins で即座に確認できる。

習得コストが少しかかる模様。

# JavaScript 入門講座

## 基本構文

```jsx
window.alert('はじめてのJavaScript!');
```

オブジェクト .  メソッド (パラメータ) という構造で記述する。

---

### defer 属性

defer 属性をつけると、html と js の読み込みが同時に行われる。
基本は `<head>` タグ内に js の読み込みファイルを記述し、 defer 属性をつける。

---

## addEventListener()

トリガーを指定するメソッド。

「何が」「どうなったら」「どうなる」を記述する。

```jsx
何が.addEventListener(どうなったら, どうなる);
```

---

## 関数の定義方法

```jsx
conts 関数名 = () => {
  //ここに実行する内容を記述
};
```

`=>` のことを**アロー関数**という。

`funcction` を使った定義方法もあるが、現在は主流ではないので、特に理由がない限りアロー関数を使用する。
