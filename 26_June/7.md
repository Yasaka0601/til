# 自分のアプリのクイズロジックを見直す。

やはり難しかったのは Structクラス についてである。

ざっくりいうと、サブクラスを簡単に作成することができる。

クラスを定義するには、以下のように記述すると思う。

```ruby
class Result
  attr_reader :multiple_answer?, :selected_ids, :correct_ids, ...

  def initialize(multiple_answer:, selected_ids:, ...)
    @multiple_answer = multiple_answer
    @selected_ids = selected_ids
    ...
  end
end

```

だが、 Struct を使うと、以下のように定義することができる。

```ruby
Result = Struct.new(:multiple_answer?, :selected_ids, :correct_ids, ..., keyword_init: true)
```

`keyword_init: true` を使うと、インスタンス生成時にキーワード引数を使うことができる。
