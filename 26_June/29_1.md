# ポイントリセットとバッジ獲得

```ruby
namespace :points do
  desc "毎週月曜日にユーザーのポイントをリセットする"
  task weekly_reset: :environment do
    # 上位３位のユーザーを total_point の降順で取得
    top_users = User.order(total_point: :desc).limit(3)

    # 上位３人のユーザーにカウントを加算し、バッジを付与
    top_users.each_with_index do |user, index|
      # カウント加算
      case index
      when 0 then user.increment!(:weekly_ranking_first_count)
      when 1 then user.increment!(:weekly_ranking_second_count)
      when 2 then user.increment!(:weekly_ranking_third_count)
      end
      # バッジ付与
      BadgeGrantService.new(user).grant_ranking_badges
    end

    # 全ユーザーのポイントをリセット
    reset_count = User.update_all(total_point: 0)
    Rails.logger.info "Reset points for #{reset_count} users"
  end
end

```

# バッジ取得の通知機能

週間ランキングのバッジを獲得した場合、マイページを開くと通知される仕組みとなっている。

users_controller.rb

```ruby
class Users::UsersController < ApplicationController
   before_action :notify_new_badges, only: :show, if: -> { user_signed_in? && current_user.public_id == params[:public_id] }

private

  def notify_new_badges
    un_notified = current_user.user_badges.where(notified_at: nil)
    if un_notified.present?
      flash.now[:new_badges] = un_notified.map(&:badge_type)
      un_notified.update_all(notified_at: Time.current)
    end
  end
end
```

```ruby
before_action :notify_new_badges, only: :show, if: -> { user_signed_in? && current_user.public_id == params[:public_id] }
```

`if : -> { }` の記述は `Lambda` である。　`Proc` と非常に似ている。
`Proc` と `Lambda` はどちらも `Proc` クラスに分類される。

https://qiita.com/y4u0t2a1r0/items/7504bf99563001cab503#proc%E3%81%A8lambda%E3%81%AE%E9%81%95%E3%81%84

`Lambda` を `if:` に渡すことで 「この条件が true のときだけ実行する」という意味になる。

```ruby
un_notified = current_user.user_badges.where(notified_at: nil)
```

`where(notified_at: nil)` で未通知のバッジを取得。

```ruby
if un_notified.present?
  flash.now[:new_badges] = un_notified.map(&:badge_type)
  un_notified.update_all(notified_at: Time.current)
end
```

「未通知のバッジがあるなら」という条件。

`flash.now[:new_badges]` は現在のリクエストのみのフラッシュ。

```ruby
flash[:new_badges] = ...      # 次のリクエストまで保持（リダイレクト後に表示）
flash.now[:new_badges] = ...  # 現在のリクエストのみ（今のビューだけで表示）
```
