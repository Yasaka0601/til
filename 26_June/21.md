# paiza

問題：1行目で文字列 s、2行目で文字列 t が入力されます。s が t の中で何回出現するかカウントして出力してください。

自分の回答

```ruby
count = 0
text = gets.chomp
letter = gets.chomp.split("")
letter_length = letter.length - 1

letter_length.times do |i|
    count += 1 if "#{letter[i]}#{letter[i + 1]}" == text
end
puts count
```

テストが通らなかった。

原因は、s が何文字かわからないのに2文字で固定にしているから。

AI からヒントをもらった。

文字列は以下のようにすると配列で取得できる

```ruby
text = "paiza"
text.length  # => 5

letter = "paizapaiza"
letter[0, text.length]  # => "paiza"
letter[1, text.length]  # => "aizap"
letter[2, text.length]  # => "izapa"
```

これを元に、以下のように修正するとテストに通過した。

```ruby
count = 0
text = gets.chomp.split("")
letter = gets.chomp.split("")

letter.length.times do |i|
    letter[i, text.length]
    count += 1 if letter[i, text.length] == text
end
puts count
```
