# JavaScript

## forEach() メソッド

無名関数の記述例

```jsx
const animals = ['猫', '🐂', '虎', 'うさぎ'];

animals.forEach((animal) => {
    console.log(animal);
})
```

関数名をつけた場合の記述例

```jsx
const animals = ['猫', '🐂', '虎', 'うさぎ'];

const showAnimals = (animal) => {
    console.log(animal);
}

animals.forEach(showAnimals)
```

作成した配列を利用して出力する。

修正した回答（テスト通過）

```ruby
# 標準入力をハッシュにする
input = {}
gets.to_i.times do
  lines =  gets.chomp.split
  input[lines[1].to_i] = lines[0]
end

# キーを並べ替える。
sorted = input.keys.sort

# 値を出力する。
input.length.times do |i|
    puts "#{input[sorted[i]]}"
end

```

AI によるリファクタ

```ruby
input = {}
gets.to_i.times do
  char, num = gets.split
  input[num.to_i] = char
end

input.sort.each do |_, value|
  puts value
end
```
