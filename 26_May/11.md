Cランク相当の文字列の問題

時間計算の考え方は、すべて分に戻して計算するだけ。

```ruby
13:00 → 13 * 60 + 0  = 780分
1時間30分           →  1 * 60 + 30 = 90分
合計                → 780 + 90     = 870分
870 / 60            → 14時
870 % 60            → 30分
結果                → 14:30
```

２４時間越えの対応

```ruby
# 870分 → 14:30（24時超えなし）
# 1460分 → 24:20 → 00:20（24時超えあり）

hour = (total_minutes / 60) % 24   # % 24 で24時超えを0時に戻す
min  = total_minutes % 60
```

- ゼロ埋めの方法
printf記法
文字列に対して `%` を使うとフォーマットの演算子になる。

```ruby
10 % 3       # => 1        （数値 % 数値 = 余り）
"%02d" % 3   # => "03"     （文字列 % 数値 = フォーマット）
```

### `%02d` の意味

記号意味

`%`ここに数値を埋め込む

`0`空いた桁を0で埋める

`2`最低2桁にする

`d`整数として扱う
