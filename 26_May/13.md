# ふわっとしていた self

self には二つの役割がある。

selfキーワードとクラスメソッドの定義である。（他は知らん）

### self キーワード

結論から言うと「メソッドの中でセッターメソッドを使う場合 `self.セッターメソッド` のようにする。
理由は、self がないとただのローカル変数への代入になる。

例

```ruby
class User
  attr_accessor :name

  def initialize(name)
    @name = name
  end

  def rename_to_bob
    # selfなしでname=メソッドを呼ぶ（？）
    name = 'Bob'
  end

  def rename_to_carol
    # self付きでname=メソッドを呼ぶ
    self.name = 'Carol'
  end

  def rename_to_dave
    # 直接インスタンス変数を書き換える
    @name = 'Dave'
  end
end
user = User.new('Alice')

# Bobにリネーム...できていない！！
user.rename_to_bob
user.name #=> "Alice"

# Carolにリネーム
user.rename_to_carol
user.name #=> "Carol"

# Daveにリネーム
user.rename_to_dave
user.name #=> "Dave"

# ----------------------------------------

def rename_to_bob
  name = 'Bob'
end

# ----------------------------------------

def rename_to_bob
  # メソッド内でセッターメソッドを呼び出す場合はselfを必ず付ける！！
  self.name = 'Bob'
end

```

上記の場合、rename_to_bob メソッドは name というローカル変数に Bob を代入しただけである。

self は自身のオブジェクトを返すので、デバックで今どのオブジェクトにいるのか確認するときは`p self` で確認できる。

### クラスメソッドの定義

クラスメソッドは普段使っている
`User.find`
`User.where` 
などである。

クラスメソッドは「オブジェクト全体」や「作成前」に関する処理をしたい場合に定義する。

例

```ruby
class User
  def self.create_guest  # クラスメソッド
    new('ゲスト', 0)     # Userインスタンスを作って返す
  end

  def self.adult_age    # クラスメソッド
    18
  end
end

# インスタンスを作らずに呼べる
guest = User.create_guest   #=> Userインスタンス（name='ゲスト'）
User.adult_age              #=> 18
```

### クラスメソッドの場合、self の位置に気をつけろ！！！

- クラス構文直下の self は「クラス自身」を表す
- クラスメソッド内の self についても「クラス自身」を表す
- インスタンスメソッド内の self については「クラスから生成されたインスタンス」を表す。

例

```ruby
class Foo
  # 注：このputsはクラス定義の読み込み時に呼び出される
  puts "クラス構文の直下のself: #{self}"

  def self.bar
    puts "クラスメソッド内のself: #{self}"
  end

  def baz
    puts "インスタンスメソッド内のself: #{self}"
  end
end
#=> クラス構文の直下のself: Foo

Foo.bar #=> クラスメソッド内のself: Foo

foo = Foo.new
foo.baz #=> インスタンスメソッド内のself: #<Foo:0x000000012da3e2f0>

```

## モンキーパッチ

既存のメソッドを上書きして、自分が期待する挙動に変更すること
オーバーライドと似ているが少し違う

|  | オーバーライド | モンキーパッチ |
| --- | --- | --- |
| 対象 | 自分が作ったクラス | 既存・組み込みクラス |
| 方法 | 継承して上書き | クラスを直接開いて変更 |
| リスク | 低い | 高い |

モンキーの意味は

monkey」には動詞として「いたずらする・むやみにいじる」という意味があります。

学んだこと

- sort_by　について

```ruby
sort_by { |g, s| [s, g] }   # 昇順
sort_by { |g, s| [-s, -g] } # 降順（マイナスをつける）
```

`[s, g]` の動作

```ruby
people.sort_by { |g, s| [s, g] }
```

配列 `[s, g]` は**左から順番に比較**します。

`① まず s（銀）で比較
② s が同じだった場合のみ g（金）で比較`

```ruby
people = [[2,3], [0,4], [5,0], [3,3]]

# [s, g] で比較すると
# [2,3] → [3, 2]
# [0,4] → [4, 0]
# [5,0] → [0, 5]
# [3,3] → [3, 3]

# sで並べると
# [0, 5]  ← s=0
# [3, 2]  ← s=3
# [3, 3]  ← s=3（sが同じなのでgで比較 → 2 < 3）
# [4, 0]  ← s=4
```
