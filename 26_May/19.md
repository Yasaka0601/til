# Paiza

**ハッシュについて**

`{ }` と `Hash.new(0)` の違い。

共通点
どちらも最初は空っぽのハッシュ

```ruby
hash = {}          # => {}
hash = Hash.new(0) # => {}
```

違う点
存在しないキーにアクセスした時に返す値が違う

```ruby
hash = {}
hash["Kyoko"]  # => nil

hash = Hash.new(0)
hash["Kyoko"]  # => 0
```

なぜ、重要？

```ruby
hash["Kyoko"] += 1
# ↓
hash["Kyoko"] = hash["Kyoko"] + 1
#                    ↑ここが問題
```

### 一言でまとめると

- 「知らないキーを聞かれた時、`nil` を返すか `0` を返すかの違い」です。集計処理には `Hash.new(0)` が便利
