# パターンマッチ

`case` で `when` ではなくて `in` を使う。
`in [ローカル変数]` 

言語化が難しいけど、結構使えそうな機能

パターンマッチ、色々種類があって覚えるのは無理

- value パターン
in 節に数値や文字列を指定する。
一つもパターンにマッチしなければ、エラーとなる。
が `else` を使うとエラーを回避できる。

- variable パターン
in 節の後に変数を記述すると、ローカル変数の宣言と代入を同時にできる。

```ruby
country = 'india'
case country
in 'japan' # value型
  'こんにちは'
in 'us' # value型
  'Hello'
in 'italy' # value型
  'Ciao'
in obj ##### これだけvariable型 #####
  "Unknown: #{obj}"
end
```

事前に定義した変数を使う場合、ピン演算子を使う

ピン演算子 `^` 

インスタンス変数を使うとSyntaxError となる。 

- array パターン
in 節の後に [ ] を記述する。
`in [a, b, c]` 
配列の要素が３つであれば `[ ]` に記述した要素に値が代入される。

### `===` ケース等値演算子

---

### 概要

`case/when` の内部で自動的に使われる比較演算子。「右辺が左辺の条件に当てはまるか」を判定する。直接使うことは少ない。

---

### `==` との違い

| 演算子 | 意味 |
| --- | --- |
| `==` | 値が等しいか |
| `===` | 右辺が左辺の条件に当てはまるか |

---

### 左辺の種類による動作の違い

ruby

`# 範囲オブジェクト → 含まれるか
(1..10) === 5       # => true
(1..10) === 11      # => false

# クラス → インスタンスか
String === "hello"  # => true
String === 1        # => false

# 正規表現 → マッチするか
/hello/ === "hello world"  # => true
/hello/ === "goodbye"      # => false

# 値 → ==と同じ
1 === 1  # => true
1 === 2  # => false`

---

### case/when の内部動作

ruby

`case x
when 1..10   # (1..10) === x
when String  # String === x
when /hello/ # /hello/ === x
end`

`when` の後に何が来るかによって判定の意味が変わる。
