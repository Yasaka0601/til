- `even?` メソッドと `odd?` メソッドについて。

回答

```ruby
def select_even_numbers(numbers)
  numbers.select{|n| n % 2 == 0}
end
puts select_even_numbers([1, 2, 3, 4, 5, 6])
```

模範回答

```ruby
def select_even_numbers(numbers)
  numbers.select { |num| num.even? }
end
puts select_even_numbers([1, 2, 3, 4, 5, 6])
```

`n % 2 == 0` は `even?` メソッドに置き換えられる。
`even?` は偶数を判定するメソッド。
偶数なら `true` を返し、奇数なら `false` を返す。

逆に、奇数判定には `odd?` を使う。

- FizzBuzz を美しく書きたい

回答

```ruby
def fizz_buzz(n)
  array = []
  n.times do |i|
    x = i + 1
    if x % 15 ==0
      array << "FizzBuzz"
    elsif x % 5 ==0
      array << "Buzz"
    elsif x % 3 ==0
      array << "Fizz"
    else
      array << x
    end
  end
  array
end
p fizz_buzz(15)
```

模範回答

```ruby
def fizz_buzz(n)
  (1..n).map do |num|
    if num % 15 == 0
      "FizzBuzz"
    elsif num % 3 == 0
      "Fizz"
    elsif num % 5 == 0
      "Buzz"
    else
      num
    end
  end
end
puts fizz_buzz(15)
```

1からnまでの数値を扱いたい、と言う場合は範囲オブジェクトを使え。
（範囲オブジェクトは英語で「レンジ」って言うらしい）
そしたら、 `map` が使えるから。
