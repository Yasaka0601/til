# Ruby module

- モジュールをクラスにinclude して機能を追加することを**ミックスイン**という。
- モジュールのメソッドをクラスメソッド（selfのやつ）にするためには、include 先のクラスで
`extend モジュール名` のように定義する（include は使わない）

モジュールのメソッドをインスタンスメソッドとして追加
`include` を使用。

モジュールのメソッドをクラスメソッドとして追加
`extend` を使用。
- `each_char` メソッドは文字列に対して、繰り返し処理をする。

例

```ruby
"hello世界".each_char {|c| print c, ' ' }
# => h e l l o 世 界
```

- モジュールの名前空間
同じ名前のクラス名を定義した時に活躍する。
`モジュール名::クラス名` のように `::` で使い分ける。
- `module_function` メソッド
クラスメソッド、普通のメソッド両方使えるようにできる。
ただ、メソッドは private メソッドになる。

`%=` 記法。
`+=` と同じノリで、余りを変数に積む。

### 仲間一覧
| 記法 | 意味 |
| --- | --- |
| `x += 1` | `x = x + 1` |
| `x -= 1` | `x = x - 1` |
| `x *= 2` | `x = x * 2` |
| `x /= 2` | `x = x / 2` |
| `x %= 2` | `x = x % 2` |
