# Ruby チェリー本を読む

- assert （アサート）と refute （リフュート）

| メソッド | 意味 | テストが通る条件 |
| --- | --- | --- |
| assert (アサート） | 〜であると主張する | 結果が真 |
| refute(リフュート） | 〜でないと主張する | 結果が偽 |

```ruby
assert 1 == 1  # 真なのでテスト通過
refute 1 == 2  # 偽なのでテスト通過

assert 1 == 2  # 偽なのでテスト失敗
refute 1 == 1  # 真なのでテスト失敗
```

- indexメソッド
このメソッドは配列の中から、引数に合致する要素の添え字を返す
見つからない場合は `nil` を返す。

```ruby
[:umeda, :juso, :mikuni].index(:juso) #=> 1 
```

```ruby
people, _, k = gets.split

people.to_i.times do
  puts gets.split.count(k)
end
```

### 注目ポイント

- 使わない変数は `_` と書くのがRubyの慣習らしい。
- 配列への代入をなくした

```ruby
# 変更前
count_number = []
count_number = gets.split
puts count_number.count(k)

# 変更後
puts gets.split.count(k)
```

`puts gets` のように `puts` には `gets` を渡すことができる。
