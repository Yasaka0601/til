修正点は

```ruby
def fizz_buzz(n)
  new_array = []
  n.times do |y|
    x = y + 1
    if x % 3 == 0 && x % 5 == 0
      new_array << "FizzBuzz"
    elsif x % 5 == 0
      new_array << "Buzz"
    elsif x % 3 == 0
      new_array << "Fizz"
    else
      new_array << x  # ← ここが抜けていた
    end
  end
  new_array  # ← pではなく、そのまま返す
end
```

あと少しだった。
模範解答は

```ruby
def fizz_buzz(n)
  (1..n).map do |num|
    if num % 15 == 0
      "FizzBuzz"
    elsif num % 3 == 0
      "Fizz"
    elsif num % 5 == 0
      "Buzz"
    else
      num
    end
  end
end
puts fizz_buzz(15)
```

修正点

1.  範囲オブジェクトを使っている。
`x = y + 1` と記述していたが `(1..n)` で良い。
2. `map` メソッドを使う。
`map` は配列を操作するメソッドなので新しい配列を作成する必要がない。
3. 15の倍数の判定方法
`if x % 3 == 0 && x % 5 == 0`
15で割り切れるかチェックする方がシンプル
`if num % 15 == 0`

- テーブル設計において、テーブル名の命名規則として正しいものはどれですか？
「テーブルは単数形で表現する」を選択して不正解
正解は「テーブル名は複数形で表現する」
    
    **テーブル名の命名規則：**
    
    - テーブル名は基本的に**複数形**で表現する
    - 1つのテーブルに複数のレコードが格納されることを表現している
    - 例：ユーザー情報を管理するテーブル → `users`
