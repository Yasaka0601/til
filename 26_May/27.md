# paiza

前回、自力でできなかった問題ができた。
問題が解けた瞬間は癖になるなこれ。
嬉しいのでコードを貼る。

```ruby
# ハッシュを作成する
names = {}
gets.to_i.times do
 names[gets.chomp] = 0
end

# ダメージ計算
gets.to_i.times do
  name, damage = gets.split
  names[name] += damage.to_i
end

# 出力
puts names[gets.chomp]

```
