### `sort_by` について

`sort_by` の挙動を忘れていたので、もう一度、復習する

`-` を付ける降順になる。

```ruby
array = [[2, 1], [1, 3], [3, 2]]

# 昇順（小さい順）
array.sort_by { |x, y| y }
# => [[2,1], [3,2], [1,3]]  yが小さい順

# 降順（大きい順）
array.sort_by { |x, y| -y }
# => [[1,3], [3,2], [2,1]]  yが大きい順

# 複数条件の場合
array.sort_by { |x, y| [-y, -x] }
# この場合、まず、yから比較し、値が同じであれば、xで比較し、降順に並び替える。
```

### [`Array.new`](http://Array.new) の挙動について

`Array.new(n)` については、要素が `nil` の配列を `n` 個作るという意味

```ruby
Array.new(3)
# => [nil, nil, nil]  要素がnilの配列を3つ作る
```

`Array.new(n) { 0 }` のようにすると、ブロックの戻り値で配列を埋める

```ruby
Array.new(3) { 0 }
# => [0, 0, 0]  ブロックの戻り値で要素を埋める

Array.new(3) { gets }
# => getsを3回呼んだ結果で配列を作る
```

今回のコードを分解すると、以下のようになる。

```ruby
Array.new(gets.to_i) { gets.split.map(&:to_i) }
#          ↑               ↑
#     配列の要素数       各要素の中身

# 入力が
# 3
# 2 1
# 1 2
# 5 0
# の場合

Array.new(3) { gets.split.map(&:to_i) }
# 1回目のブロック: gets → "2 1" → [2, 1]
# 2回目のブロック: gets → "1 2" → [1, 2]
# 3回目のブロック: gets → "5 0" → [5, 0]
# => [[2,1], [1,2], [5,0]]
```
