# 正規表現

正規表現を作っていくときは、[Rubular](https://rubular.com/)を使ってトライアンドエラーを繰り返して作成していく。

## 正規表現オブジェクトを作成する際は // だけではない

1. [`Regexp.new`](http://Regexp.new) を使った方法（エイリアスは `Regexp.compile` )
`Regexp.new(’\d{3}-\d{4}’)` 

2. `%r` 記法
`%r !https://example\.com!` 
メリットは、スラッシュをエスケープしなくて良い。
! ! で囲む他にも { } で囲むことも可能。

xオプションは便利。正規表現にコメントを付けられる。
あとでコードを見返した時にわかりやすい。
