- ファイル・ディレクトリの扱い
File クラス
Dir クラス
FileUtils クラス　（ファイルユータルス）
Pathname クラス
がある。

FileクラスとDirクラスは、ファイルの読み書きに使う。
FileUtilsクラスは、ファイルのコピーや、削除などを **便利(Utils)** に実行するクラス。
Pathname クラスは、パス名をオブジェクトっぽく扱って、いろんなメソッドを使って、ファイルなのかディレクトリなのかを返す。

- Ruby のバージョンアップの際に気を付ける点

既存のコードで警告文が表示されるのか！
非推奨機能は警告文が表示され、将来機能が削除される可能性がある。
なので、以下の非推奨警告を出力するコードを仕込む。

```ruby
Warning[:deprecated] = true
```

- リテラルとは
ソースコードに直接書いた値そのもの

```ruby
42          # 整数リテラル
"hello"     # 文字列リテラル
[1, 2, 3]   # 配列リテラル
{ a: 1 }    # ハッシュリテラル
true        # 真偽値リテラル
```

定数との違い

```ruby
# リテラル → 値そのもの
42
"hello"

# 定数 → 値に名前をつけたもの
MAX = 42
GREETING = "hello"
```

|  | リテラル | 定数 |
| --- | --- | --- |
| 何か | 値そのもの | 名前のついた入れ物 |
| 例 | `42` | `MAX = 42` |
| 変更 | そもそも変更という概念がない | 変更しようとすると警告が出る |
