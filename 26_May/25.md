## printf記法（フォーマット記法）

**この問題は、出力方法が一番難しい**

```ruby
# 24時間超えとゼロ埋めをまとめて処理
puts "%02d:%02d" % [new_hour % 24, new_minute]
```

`%` 演算子の使い方。

```ruby
"%02d" % 3  # => "03"
# 左側: 書式文字列
# 右側: 埋め込む値
```

文字列に対して `%` を使うと「書式に従って値を埋め込む」という意味になる。

`%02d` の意味

```ruby
% → ここに値を埋め込む
0 → 空いた桁を0で埋める
2 → 最低2桁にする
d → 整数として扱う

"%02d" % 3   # => "03"  1桁なので0で埋める
"%02d" % 14  # => "14"  2桁なのでそのまま
"%02d" % 0   # => "00"  0なので00になる
```

```ruby
puts "%02d:%02d" % [(new_hour) % 24, new_minute]
#     ↑書式文字列  　　 ↑1つ目の値        ↑2つ目の値
```

複数の値を埋め込む時は、配列で渡す。

```ruby
"%02d:%02d" % [3, 5]
#  ↑           ↑  ↑
# 書式        時  分
# => "03:05"
```
