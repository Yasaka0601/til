９回目の処理で、 10 % 10 が ０となっていない。

**原因**

`%` は `+` よりも演算子の優先順位が高いから。

以下のように計算されてしまう

```ruby
index = (start-1) + (i % test_chair)
# 9回目: 2 + (8 % 10) = 2 + 8 = 10
```

解答

```ruby
chair = gets.chomp.to_i
people, start = gets.split.map(&:to_i)
chair_array = gets.split.map(&:to_i)
result = "Yes"

people.times do |i|
  index = (start-1 + i)  % chair 
  if chair_array[index] == 0
    chair_array[index] = 1
  else
    result = "No"
  end
end

if result == "Yes"
    puts "#{result}"
    puts "#{chair_array.join(" ")}"
else
    puts "#{result}"
end

```

end
