各条件を `||` で連結する。

### ルール１　発言は、単語リストにある K 個の単語のうちのいずれかの単語でなければならない。

```ruby
!word_list.include?(word) ||
```

### ルール２　最初の人以外の発言の頭文字は、直前の人の発言の最後の文字と一緒でなければならない。

```ruby
(!prev_dropped && comment_last && comment_last[-1] != word[0])
```

ルール２はややこしい。

前2つは「ガード条件」

**① `!prev_dropped`**

問題文「ルールを破った人の後続の人は、ルール2を守る必要はない」

```ruby
直前の人が脱落した（prev_dropped = true）
→ ルール2免除
→ !prev_dropped が false になり、全体が false（違反にならない）
```

**② `comment_last`**

最初の発言では `comment_last` が `nil` です。

```ruby
comment_last が nil
→ nil[-1] を実行するとエラー！
→ その前に comment_last で false になり、右側は評価されない（エラー回避）
```

日本語に直すと

「直前の人が脱落しておらず、
かつ 前回の発言が存在し、
かつ 頭文字が一致しない」
なら ルール2違反

### `&&` の重要な性質

`&&` は**左が false なら右を評価しない**（短絡評価）。

### ルール３　今までに発言された単語を発言してはならない。

```ruby
comment_result.include?(word) ||
```

### ルール４　z で終わる単語を発言してはならない。

```ruby
word[-1] == "z" ||
```

    `||` で連結しているので、一つでも `true` なら、脱落。

## この問題は人のループが最難関

正常回答の場合

```ruby
index = (index + 1) % people.length
```

```ruby
people = [1, 2, 3] の場合

index=0 → (0+1) % 3 = 1  # 次は2人目
index=1 → (1+1) % 3 = 2  # 次は3人目
index=2 → (2+1) % 3 = 0  # 次は1人目（先頭に戻る！）
```

脱落の時

```ruby
people.delete_at(index)
index = 0 if index >= people.length
```

```ruby
people = [1, 2, 3]、index=1（2人目の番）
2人目が脱落 → delete_at(1)
people = [1, 3]
        ↑この時、3人目がindex=1の位置に移動してくる！

次の発言者は people[1] = 3人目 ✅
indexは動かさなくて良い
```

### では `index = 0 if ...` は何のため？

**末尾の人が脱落した場合**の対策です。

```
people = [1, 2, 3]、index=2（3人目の番）
3人目が脱落 → delete_at(2)people = [1, 2]
people[2] は存在しない！
（indexが範囲外）→ index = 0 に戻して1人目から再開
```
