AIのリファクタ

```ruby
board = Array.new(5) { gets.chomp.chars }

lines = []

# 横
lines += board

# 縦
lines += board.transpose

# 斜め
lines << 5.times.map { |i| board[i][i] }
lines << 5.times.map { |i| board[i][4 - i] }

winner = lines.find { |line| line.uniq.length == 1 && line[0] != "." }&.first

puts winner || "D"
```

---

まず、標準入力から配列を作成。

```ruby
board = Array.new(5) { gets.chomp.chars }

p board

# 出力結果
[["X", "X", "O", "X", "O"], 
 ["O", "X", "O", "X", "X"],
 ["O", "O", "O", "O", "O"],
 ["O", "X", "O", "X", "."], 
 ["X", "O", "X", "X", "O"]]
```

`chars` メソッドは文字列の各文字を文字列の配列で返す。

https://docs.ruby-lang.org/ja/latest/method/String/i/chars.html

---

横の配列

```ruby
# 横のブロック
lines = []

lines += board
```

横、縦、斜めの配列を `lines` にまとめる。

---

縦の配列

```ruby
lines += board.transpose
```

`transpose` メソッドは二次元配列を縦の配列に変換する。

https://docs.ruby-lang.org/ja/latest/method/Array/i/transpose.html

---

lines << 5.times.map { |i| board[i][i] }

---

勝者判定

```ruby
winner = lines.find { |line| line.uniq.length == 1 && line[0] != "." }&.first
puts winner || "D"
```

`line` について

```ruby
lines = [
  ["O","O","O","O","O"],  # 横1行目
  ["X","X",".","X","."],  # 横2行目
  ...
]

lines.find { |line| ... }
# line は上記の各配列が1つずつ入る
```

`uniq` について

```ruby
["O","O","O","O","O"].uniq  # => ["O"]        要素が1種類
["O","X","O","O","O"].uniq  # => ["O", "X"]   要素が2種類
["O","X",".","O","X"].uniq  # => ["O","X","."] 要素が3種類
```

`uniq.length == 1` の意味

```ruby
["O","O","O","O","O"].uniq.length  # => 1  全部同じ！→ 勝者確定
["O","X","O","O","O"].uniq.length  # => 2  違う要素がある → 勝者なし
```

---

可読性を重視したコードは以下のようになる。

```ruby
board = Array.new(5) { gets.chomp.chars }

lines = []
lines += board
lines += board.transpose
lines << 5.times.map { |i| board[i][i] }
lines << 5.times.map { |i| board[i][4 - i] }

winner = nil

lines.each do |line|
  next if line[0] == "."
  winner = line[0] if line.uniq.length == 1
end

puts winner || "D"
```
