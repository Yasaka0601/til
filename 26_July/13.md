# Java学習

## Javaは引数にもデータ型を指定する必要がある。

```java
public static void greet(String name //データ型を指定// ) {
    System.out.println("こんにちは、" + name + "さん");
}
```

複数の引数を受け取るメソッド

```java
public class Main {
    public static void introduce(String name, int age // (,)で区切っている// {
        System.out.println("私の名前は" + name + "です");
        System.out.println("年齢は" + age + "歳です");
    }

    public static void main(String[] args) {
        introduce("太郎", 20);
    }
}
```

カンマ( , ) で区切っている `String name, int age`

## メソッドの戻り値

戻り値がないメソッド

メソッド名の前に `void` （和訳：空）と記述される。

`return` の記述もない。

```java
public class Main {
    public static void introduce(String name, int age) { //この行の void と記述されている部分//
        System.out.println("私の名前は" + name + "です");
        System.out.println("年齢は" + age + "歳です");
    }

    public static void main(String[] args) {
        introduce("太郎", 20);
    }
}
```

戻り値があるメソッド

```java
public class Main {
    public static String getGreeting(String name) { //void が String になっている//
        return "こんにちは、" + name + "さん"; //return を追記//
    }

    public static void main(String[] args) {
        // メソッドの戻り値を変数に代入
        String message = getGreeting("太郎");
        System.out.println(message);
    }
}
```

`String getGreeting(String name)` このようにメソッド名の前に `void` ではなくデータ型を記述している。

`return` の後に返したい値を記述し、その値を呼び出し元に返している。
