# Java

## 配列

Java は格納するデータ型が統一されている。

 `{}` の中にカンマ区切りで要素を記述する。

```java
// 値を指定して作成
int[] prices = {100, 200, 300};

// 文字列の配列
String[] names = {"太郎", "花子", "次郎"};
```

## ループ処理

for文

```java
for (int price : prices) {
    System.out.println(price);
}
```

`for (int price : prices)` は「`prices` 配列の中のそれぞれの要素について、`int` 型の変数 `price` に入れて処理する」

for のブロックパラメータにも型の宣言が必要。

カリキュラムでは、突然、配列を作成する記述で `new` が出てくる。

```java
public class Main {
    public static void cashier(int[] prices) {
        for (int price : prices) {
            System.out.println(price);
        }
    }

    public static void main(String[] args) {
        cashier(new int[]{100, 200, 300});
    }
}
```

これは、変数を作成しないで、メソッドの引数に配列を渡す場合、 `new` が必要になる。

変数に配列を代入して配列を作成する場合、 `new` は省略されている。

```java
int[] prices = {100, 200, 300};
```

これは以下と全く同じ意味

```java
int[] prices = new int[]{100, 200, 300};
```

Javaが「左側で `int[] prices` と型を宣言しているから、右側は当然int型の配列だよね」と推測できるため、`new int[]` の部分を省略しても許してくれる

なので、メソッドの引数として配列を渡す場合は、以下のようになる。

```java
cashier({100, 200, 300});             // ✕ エラー
cashier(new int[]{100, 200, 300});   // ○ OK
```

小テスト

問題

`totalWithTax`メソッドを実装してください。

- 引数としてint型の配列（複数の商品価格）を受け取る
- 配列内のすべての価格を合計し、消費税10%を加えた金額を整数（int型）で返す
- 小数点以下は切り捨てる

自分のコード（不正解）

```java
public class Main {
    public static int totalWithTax(int[] prices) {
        // コードを記載
        int total = 0;
        for (int price : prices){
          total += price;
        }
        return (total * 1.1) + "円";
    }

    public static void main(String[] args) {
        System.out.println(totalWithTax(new int[]{100, 200, 300}));
    }
}
```

このコードが動かない理由は、型の変換。

`(total * 1.1)` のデータ型は `double` 型（少数）

でも出力は `int` である必要がある。

```java
public static int totalWithTax(int[] prices)
```

メソッドの宣言で、戻り値の型を `int` にしている。

なので、以下のように修正するとコードは動く

```java
return (int)(total * 1.1);
```

ちなみに、今回の問題は「円」は必要なかった。
