# Java学習

## 四則演算

```java
// 足し算
System.out.println(10 + 5);   // 15

// 引き算
System.out.println(10 - 5);   // 5

// 掛け算
System.out.println(10 * 5);   // 50

// 割り算
System.out.println(10 / 5);   // 2
```

データ型の整数と少数の違いについて。

整数は `int` 

少数は `double` （「ダブル」と読む。なぜなのか、、、）

`int` 同士の割り算は、小数点が切り捨てとなる。

```java
System.out.println(10 / 3);    // 3（小数点以下が切り捨て）
System.out.println(7 / 2);     // 3（3.5ではなく3）
```

一方で、 `double` 同士の割り算であれば、結果も `double` になる。

```java
System.out.println(10.0 / 3);  // 3.3333333333333335
System.out.println(7.0 / 2);   // 3.5
```

左辺か右辺、どちらかに小数点付きの数値が含まれると結果は `doble` になる。

## キャスト演算子

`(int)` を付けると、データ型を `(int)` に変換できる。

記述例

```java
// 間違い：price1だけがキャストされる
(int) price1 + price2 * 1.1

// 正しい：計算結果全体をキャストする
(int)((price1 + price2) * 1.1)
```

小テストの回答

```java
public class Main {
    public static int cashier(int price1, int price2) {
        // コードを記載
        return (int)((price1 + price2) * 1.1);
    }

    public static void main(String[] args) {
        System.out.println(cashier(100, 200));
    }
}
```
