# Java キャッチアップ

Java の初めに記述する「おまじない」

```java
public class Main {
    public static void main(String[] args) {
        // プログラムを記述する箇所（ここから）
        System.out.println("Hello World");
        // （ここまで）
    }
}
```

`public class Main { ... }` と `public static void main(String[] args) { ... }` がおまじない。

プログラムを記述する箇所は
`System.out.println("Hello World");` の部分。

基本ルール

文の末尾には `;` （セミコロン）が必要。
忘れるとコンパイルエラーになる。

## println　（「print line」の略）

`System.out.println()` は画面に文字を表示するための命令。

文字列は `""` で囲む。

## 変数の宣言

```java
String name = "太郎";

int age = 20;
```

変数名の前に、データ型を宣言する。

## 変数名の付け方

キャメルケースを使用。
小文字で始めて、単語の区切りを大文字にする。

例：`totalPrice`（合計金額）
        `userName`（ユーザー名）
        `itemCount`（アイテム数）

## メソッドの定義方法

```java
public static void greet() {
    System.out.println("Hello World");
}
```

`public static void` はおまじない。
この後ろにメソッド名と括弧を記述する。

```java
public class Main {
    public static void greet() {
        System.out.println("Hello World");
    }

    public static void main(String[] args) {
        // メソッドを呼び出す
        greet();
    }
}
```

`String[] args` はおまじない。

AI のリファクタ

```ruby
users = {}
gets.to_i.times do
  name, type = gets.split ##### 多重代入 #####
  users[name] = type
end

fortunes = {}
gets.to_i.times do
  type, result = gets.split ##### 多重代入 #####
  fortunes[type] = result
end

users.each do |name, type|
  puts "#{name} #{fortunes[type]}"
end
```

ポイントは多重代入にしたこと。

さらにリファクタ

```ruby
users = Array.new(gets.to_i) { gets.split }.to_h
fortunes = Array.new(gets.to_i) { gets.split }.to_h

users.each { |n, t| puts "#{n} #{fortunes[t]}" }
```
