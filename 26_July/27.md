**AWS Lambda** 

サーバーを用意しなくても、コードだけ書けば動かせるサービス

サーバーレスとは、開発者がサーバーを用意しなくても良いという意味。

感想：バックエンドのサーバーっぽいね。

**API Gateway**

AWS が提供している外からのリクエストを受け取る玄関口。

ユーザー → API Gateway → AWS Lambda → 処理 → レスポンス

感想：GUI でルーティングっぽいものを作成するのは分かりやすい。
なんと、テストまでできる。

**CORS(Cross-origin resource sharing)** 

デフォルトでは、異なるドメイン間のリクエストはブラウザがブロックしている。

なぜなら、悪意のあるサイトが勝手に銀行などの別サービスのAPIを呼び出して、ユーザーの情報を盗むのを防ぐため。

CORS は別のオリジン（ドメイン）から API を呼び出せるようにする仕組み。

**結合テスト** とは
複数の部品を組み合わせた時に、期待通りに動くのかテストすること

イメージ

```ruby
単体テスト → 部品1つずつのテスト
           （Lambdaだけ、API Gatewayだけ）

結合テスト → 部品を繋げた時のテスト
           （API Gateway → Lambda → DynamoDB が全部繋がって動くか）
```
